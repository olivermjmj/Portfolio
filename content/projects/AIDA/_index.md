## Description

AIDA (AI-Driven Applications) is an elective course focused on how artificial intelligence and Large Language Models can be integrated into modern software development.

The course focuses on both the technical implementation of AI-powered applications and the development process surrounding them. This includes working with LLM APIs, Retrieval-Augmented Generation (RAG), AI coding agents, prompt engineering, structured output, and AI-assisted development workflows.

Throughout the course, different cases and experiments are documented in this portfolio. The goal is not only to use AI tools, but to understand how they work, when they provide value, their limitations, and how they can be integrated into software systems.
